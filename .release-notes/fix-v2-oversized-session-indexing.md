# 超长会话可以正常完成索引
<!-- release-target: v2 -->

## Bug 修复

- 修复单个会话轮次内容过长时可能反复索引失败的问题；超长会话现在可以完整保存、正常刷新，并继续通过末尾关键词搜索，不会截断原始内容。
- 修复从 Finder 打开应用时，部分 Node 安装方式下无法启动的问题，并继续优先使用当前安装版本。
- 相同会话持续索引失败时会合并诊断记录并延迟重试；修改会话、主动刷新或重启应用后可重新尝试，不会永久跳过失败会话。
- 工作台优先展示会话、工作流和聊天入口，用量信息移至下方；主导航按用途分组，宽屏下显示完整分组名称，并改善工作台小字的可读性。
